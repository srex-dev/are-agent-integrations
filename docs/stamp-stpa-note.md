# STAMP/STPA Framing For Tool Governance

ARE's MCP integration treats tool execution as a controlled action, not a text
moderation problem.

STAMP/STPA language is useful for launch content because it gives builders a
clean way to talk about accidents:

- unsafe control action: a tool call that should not execute in that context
- controller: agent/framework deciding whether to call a tool
- actuator: MCP tool/server boundary
- process model: passport, scope, policy, and resource metadata
- feedback: public-safe proof result and denial reason

This note is framing only. Public claims should cite the specific STAMP/STPA
source being discussed and the benchmark report generated by this repository.
